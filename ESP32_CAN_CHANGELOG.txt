SUMMARY
-------
Added CAN bus support for ESP32-S3 boards using the ESP32-S3 TWAI (CAN)
peripheral via the ESP-IDF TWAI driver, which enables the full DroneCAN
stack (AP_CANManager + AP_DroneCAN) on ESP32-S3 for the first time.
Enabled on both S3 boards: esp32s3devkit and esp32s3empty.

NEW FILES (2)
-------------
libraries/AP_HAL_ESP32/CANIface.h   (137 lines)
  - ESP32::CANIface, an AP_HAL::CANIface implementation backed by TWAI
  - requires HAL_ESP32_CAN_TX_PIN / HAL_ESP32_CAN_RX_PIN from board header
  - typedef ESP32::CANIface HAL_CANIface (used by AP_CANManager)
  - static_assert(HAL_NUM_CAN_IFACES == 1): S3 has one TWAI controller

libraries/AP_HAL_ESP32/CANIface.cpp  (384 lines)
  - init(): twai_driver_install + twai_start; bitrate -> timing config for
    1M/800k/500k/250k/125k/100k/50k/25k; SilentMode -> listen-only
  - send()/receive(): hardware queue <-> software RX queue (64 frames),
    invokes base-class callbacks (MAVLink CAN frame forward/logging)
  - select()/set_event_handle(): readiness flags + blocking waits on the
    DroneCAN event semaphore
  - FreeRTOS alert task: turns TWAI alerts (RX data, TX drained, bus-off)
    into semaphore wakeups; automatic bus-off recovery via
    twai_initiate_recovery() + twai_start() on BUS_RECOVERED
  - stats (get_stats/get_statistics) feeding DroneCAN iface-down logic
  - guarded by #if HAL_NUM_CAN_IFACES > 0 (empty TU on non-CAN boards)

REVIEW FIXES (after initial green builds)
-----------------------------------------
1. Removed use of TWAI_ALERT_TX_QUEUE_FULL (does not exist in ESP-IDF 5.3)
2. Race fix: removed the cached tx_queue_full_ flag. A full-queue timeout
   in send() could race with a concurrent TX-drain alert and leave the flag
   stuck true, permanently blocking TX. twai_transmit() is now the ground
   truth for space; TX alerts unconditionally wake retrying senders.

USAGE
-----
  wiring: ESP32-S3 TX/RX -> transceiver CTX/CRX (3.3V part, e.g. SN65HVD230)
          + GND + 3.3V, 120 ohm termination at each bus end
  params (work out of the box):
    CAN_P1_DRIVER   = 1
    CAN_D1_PROTOCOL = 1 (DroneCAN)
    CAN_P1_BITRATE  = 1000000 (1M/800k/500k/250k/125k/100k/50k/25k)
  disable: set HAL_NUM_CAN_IFACES 0 in the board header
